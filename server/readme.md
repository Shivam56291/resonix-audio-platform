## 🔐 Environment Variables

Create a `.env` file in the **server root**.

```env
MONGODB_URI=
PORT=

MAILTRAP_USER=
MAILTRAP_PASS=

VERIFICATION_EMAIL=
PASSWORD_RESET_LINK=
SIGN_IN_URL=

JWT_SECRET=
```

<p align="center"> ⚠️ Do not commit `.env` to version control </p>
